# Project Zed
# NYC on a Student Budget

A travel guide for college students who want to visit New York City alone or with friends and plan their spending.

## Current Feature

A group budget calculator that uses:
- Number of travelers
- Food and activities cost per person
- Total shared costs, such as lodging and transportation

It calculates the estimated group total and cost per person by splitting shared expenses equally.

## Planned Features

- Browse affordable NYC places.
- Filter places by category and estimated cost.
- Add places to a trip plan.
- Save the plan using localStorage.

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

Download or clone this repository and open index.html in a browser.

## How to Use

1. Enter the number of travelers.
2. Enter the food and activities cost for one person.
3. Enter the total shared costs for the whole group.
4. Click Calculate.

All amounts are in US dollars. Estimates only cover the costs entered.
